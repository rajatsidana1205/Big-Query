# Big-Query – Marketing Analytics with SQL

## 📌 Project Overview

This repository contains a collection of SQL-based marketing analytics projects developed using **Google BigQuery**.

The projects demonstrate how SQL and Google Analytics data can be used to analyse website performance, customer behaviour, revenue trends, and marketing outcomes.

The objective is to transform raw analytics data into meaningful business insights that can support data-driven marketing and business decisions.

## 📂 Projects

### 1. Monthly Revenue Trend

**File:** `Monthly Revenue Trend.sql`

This analysis focuses on understanding revenue performance over time.

Key areas of analysis include:

- Monthly revenue trends
- Revenue performance over different periods
- Identification of changes in revenue
- Comparison of performance across months
- Understanding overall revenue patterns

This analysis can help businesses identify periods of strong and weak revenue performance and support future planning.

---

### 2. Waterproof Backpack Analysis

**File:** `Waterproofbackpack_analysis.sql`

This project analyses customer and product behaviour related to the **Waterproof Backpack** product.

The analysis uses Google Analytics data to investigate customer interactions and purchasing behaviour.

Key areas include:

- Product performance
- Customer engagement
- Product interactions
- Purchase behaviour
- Revenue generated
- Conversion-related insights

The purpose is to understand how customers interact with the product and identify opportunities to improve marketing and sales performance.

---

### 3. Web Analytics

**File:** `WebAnalytics.sql`

This project focuses on analysing website and Google Analytics data to understand user behaviour and website performance.

Key areas of analysis include:

- Website traffic
- User behaviour
- Sessions
- Engagement
- Product interactions
- Transactions
- Revenue
- Marketing performance

The analysis demonstrates how SQL can be used to extract meaningful insights from large-scale web analytics datasets.
